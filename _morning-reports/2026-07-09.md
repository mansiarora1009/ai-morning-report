### 2. Agent Experience is replacing Developer Experience — a new infrastructure concept worth knowing
**What it is:** Modal CTO Akshat Bubna (fresh off a $355M Series C) articulated clearly: all cloud infrastructure was built for humans — docs you read, dashboards you interpret, YAML you write. Agents can't do any of that. So you need new primitives: fast sandboxes, burst elasticity (RL training can need 100k sandboxes simultaneously), snapshotted GPUs, and observability that works when no human is reading the code.

**Why it matters:** "Developer Experience" has been the north star for dev tools for a decade. "Agent Experience" is an entirely different design target. If your audience is building anything with agents, this reframe explains why so much existing tooling feels broken when agents use it.

**Format:** Explainer

**Reel angle:** "Dev tools were built for humans. Agents break them. Here's what 'Agent Experience' actually means."
