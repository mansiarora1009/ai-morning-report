### 2. The "regression tax" — adding AI skills breaks things it already knew how to do
**What it is:** A paper summarized by @omarsar0 tracked ~6,000 paired agent runs and found that adding procedural "skills" to an agent's context created gains on some tasks while breaking many tasks the agent previously solved without them. A separate eval (EvoCode) found agents degrading across 26 sequential tasks when requirements evolved — earlier behavior breaks as new instructions accumulate.

**Why it matters:** This is the hidden cost nobody talks about when teams stuff more capabilities into their AI workflows. "More context, more skills" has a measurable failure mode. If you're building on top of AI agents, this changes how you should think about prompt and skill management.

**Format:** Explainer — "Why your AI assistant gets worse as you give it more instructions."

**Reel angle:** *More prompts, more skills, more broken outputs. Here's the regression tax nobody warned you about.*

### 3. Cursor launches Cursor Router — the model selection problem becomes infrastructure
**What it is:** Cursor shipped Cursor Router, a system that intelligently routes coding tasks to different models. They also published "Agent swarms and the new model economics" — a piece arguing that multi-agent systems require fundamentally different cost/quality tradeoffs than single-model workflows.

**Why it matters:** Model selection is becoming infrastructure, not a user choice. The question isn't "which model should I use?" — it's "how do I build a system that picks the right model for each subtask automatically?" Cursor is the first major coding tool to make this explicit.

**Format:** Shift — "AI coding tools are quietly becoming model orchestrators. Here's what that means for how you work."
