# Morning Report — 2026-08-01

## Top 3 Things Worth Paying Attention To

### 1. Stateless MCP (MCP 2.0) just made the protocol worth learning again
**What it is:** The 2026-07-28 MCP spec — dubbed "MCP 2.0" by the community — dropped the session handshake requirement. Calling an MCP tool now takes one HTTP request instead of two. Simon Willison called Tuesday "Stateless MCP day" and immediately built three things: mcp-explorer, datasette-mcp, and a new MCP client, calling it "the most significant change to MCP since it first launched." He also made the point that MCP tools are easier to audit and control than giving agents raw shell access — and small models can drive them.

**Why it matters to your audience:** Most people wrote off MCP in 2025 when Skills and shell access eclipsed it. This spec change reverses that calculus: it's now simple enough to build a server in an afternoon, and the security argument (auditable, no open internet access) is newly compelling for enterprise/workplace use.

**Format:** Explainer + First Step — "MCP is back. Here's what stateless means and why you should finally build something with it."

**Reel angle:** *"Everyone said MCP was dead. One spec change just brought it back — and now it's actually simple."*

### 2. Claude Code now lets subagents pick their own model
**What it is:** Claude Code subagents now accept their own `model` and `effort` parameters. One session can plan on Claude Opus 5 (frontier-quality reasoning) and delegate execution steps to a cheaper/faster model. This shipped in the late-July 2026 refresh that also pushed Claude Code to #1 on coding benchmarks.

**Why it matters:** This is the workflow unlock that makes multi-agent coding practical without burning budget on everything. The pattern — expensive brain, cheap hands — is how professional Claude Code users are actually working now.

**Format:** Tip — concrete and immediately actionable for anyone already using Claude Code.

**Reel angle:** *"Stop paying for Opus when you only need it for the plan. Here's the two-line change that cuts your Claude Code costs."*

### 3. DeepSeek V4-Flash 0731: same model, massive jump, from post-training alone
**What it is:** DeepSeek shipped a post-training-only update to V4-Flash with no architecture or size change (still 284B total / 13B active). Terminal-Bench jumped from 56.9 → 82.7 (+25.8 points). On Artificial Analysis, the model went from index score 40 → 50, now 1 point behind GPT-5.6 Luna — at roughly 60% lower cost. The API also added a 98% cache-hit discount: $0.0028/M cached tokens. It's now the cheapest capable model for agentic workloads.

**Why it matters:** The story isn't DeepSeek specifically — it's that post-training alone moved a model this dramatically. That's the "what changed really" take: fine-tuning and RLHF are now doing work that used to require new architectures. And for anyone building agents at scale, the price point is genuinely relevant.

**Format:** Shift — points to a bigger pattern in how models are being improved.

**Reel angle:** *"They didn't change the model. They just trained it differently — and it jumped 26 points. What that means for where AI is actually heading."*
