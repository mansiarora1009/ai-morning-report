### 1. Decision Models Just Became a Product Category
**What it is:** On the same day, OpenAI (Decisions API), Perplexity (pplx-decider-v1.1-27b), Cloudflare (clef), Microsoft (Decision-1), and Liquid (d1) all shipped "decision models" — models that return typed answers (probability, pick from a list, score) in a single forward pass instead of generating free text. The category reference point is TypeSafe's Jev, which reportedly hit $100M ARR and a $7.5B valuation just 3 weeks after launch.

**Why it matters:** Many agent steps are yes/no routing calls, not generation tasks. LangChain ran benchmarks showing that routing each task to the cheapest adequate model cut median Open SWE cost per task by **64%**. OpenAI's Decisions API claims up to 10x faster than standard completions at $0.10/M input tokens with no output charge. This is a practical shift in how agent stacks are priced and structured.

**Format:** Explainer
**Reel angle:** "You're using a sledgehammer for a thumbtack — here's the small model shift that just cut AI costs 64%"

### 2. Anthropic Opens Multi-Agent to Everyone
**What it is:** Two moves in one week. Claude Managed Agents dynamic workflows entered public beta — a lead agent writes a phased plan and fans it out to up to 1,000 subagents per run (enabled with `multiagent_20261001`). Separately, all waitlisted Claude Code Pro and Max users were admitted to Projects, where tasks run as parallel threads and sessions can run locally.

**Why it matters:** Multi-agent orchestration just crossed from "for teams with eng support" to "anyone with a Pro account." The pattern of one brain → many hands, with Anthropic handling sandboxing and context, is now a real user-accessible workflow, not a research preview.

**Format:** First Step
**Reel angle:** "You probably have Claude Code Projects access now. Here's what to actually do first."

### 3. Agent Teams Cost 5x More and Barely Help — Here's What the Data Says
**What it is:** Vals AI ran solo vs. team benchmarks on GPT-6 Sol and Opus 5.5 on Vibe Code Bench. Agent teams cost 1.8–5.1x more. Only Sol at medium effort showed meaningful gain (+7.3 points). Opus ran sequential waves with up to ~6,800 subagent tool calls per app at max effort and saw no significant improvement. Separately, LangChain found smart routing to the cheapest model beat brute-force multi-agent for cost efficiency.

**Why it matters:** The instinct to throw more agents at a problem is wrong for most tasks. The shift is from "more agents = better" to "right model for the step = better." That reframe changes how practitioners design agent harnesses.

**Format:** Shift
**Reel angle:** "I ran the benchmark: multi-agent costs 5x more and barely improves. Here's what actually does."
