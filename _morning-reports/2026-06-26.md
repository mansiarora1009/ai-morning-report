### 3. Simon Willison ran a 1.24GB AI model in the browser — Claude Code did the conversion
**What it is:** Simon ported the Moebius image inpainting model (0.2B params) to run fully client-side using WebGPU + ONNX Runtime Web, no server. Claude Code (Opus 4.8) handled the PyTorch→ONNX conversion, Hugging Face publishing, and frontend build. Key trick: CacheStorage API handles the large weight downloads.

**Why it matters:** This is a concrete template for running AI models entirely in the browser — privacy-preserving, no backend, and Claude Code did the heavy technical lift. The CacheStorage API for model weights is a pattern worth knowing.
