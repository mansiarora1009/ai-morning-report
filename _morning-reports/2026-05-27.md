### 1. The No-Code Meeting Memory System (via Michael Crist / Substack)
**What it is:** A fully prompt-driven meeting agent built on Granola (AI notetaker) + Obsidian (local Markdown vault) + Claude Desktop's Cowork project mode. Transcripts land in a folder Claude can read; a project prompt converts each one into a structured note (decisions, action items, timestamps). From there: semantic search across all past meetings, auto-generated pre-meeting briefs for recurring calls, and a daily work log written at end of day. Zero code required.

**Why it matters:** This is the first widely-shared recipe that makes Claude's file-system access a *durable memory layer* for knowledge workers — not a one-off chat. It shifts Claude from "answer-this-question" to "knows everything about my work."

**Format:** First Step — gets people who've heard of Claude projects but haven't wired them to real work to actually do it.

**Reel angle:** "Here's the exact stack I use to never forget a meeting again — and it took one afternoon to set up."

### 2. MCP Protocol v2 Finalizes July 28 (via Ben's Bites)
**What it is:** The Model Context Protocol spec upgrade lands July 28 with: built-in support for app-like interfaces, long-running tasks, stronger auth/security rules, formal versioning, and better tool definitions. WorkOS also shipped `auth.md` — an open protocol for agents to authenticate on behalf of users, filling the "how does my agent log into things" gap. MCP's "dead" narrative peaked in March; this upgrade addresses the core reliability complaints.

**Why it matters:** July 28 is the moment MCP becomes production-viable. The companies that have been waiting on the sidelines will ship MCP integrations. If you're building anything agent-adjacent, this is the infra bet to understand now — before it's mainstream.

**Format:** Shift — points to a protocol-level change that will ripple through how people build and use AI tools.

**Reel angle:** "MCP had a rough year. Here's what's changing on July 28 that makes it actually matter."

### 3. Cognitive Surrender: The Studies That Show It's Already Happening (via One Useful Thing / Ethan Mollick)
**What it is:** Mollick documents two divergent outcomes from the same AI tools. Turkish students who used ChatGPT *to do* math homework underperformed on tests; Taipei students whose AI *tailored problems* for them gained the equivalent of 6–9 months of schooling. BCG consultants using GPT-4 outperformed peers on most tasks but were *more* likely to accept the AI's wrong answers — "meaning-shaped attention vampires" that exploit our trained instinct to trust polished prose. His core argument: the difference between AI as a crutch and AI as a lever is *intentionality*, and almost nobody is being deliberate about it.

**Why it matters for Mansi's audience:** Tech workers are the heaviest AI users and the most at risk of confident-looking wrong outputs slipping through. The skill isn't prompt engineering — it's knowing when to stay engaged vs. when to hand off.

**Format:** Explainer — makes the "AI makes you dumber" discourse finally precise and falsifiable.

**Reel angle:** "Same AI tool, opposite results. Here's the BCG study nobody's talking about."
