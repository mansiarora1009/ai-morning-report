## Top 3 Things Worth Paying Attention To

### 1. Decision models just became a product category overnight — and they change how you build with AI

**What it is:** Multiple vendors shipped "decision" models on the same day. These models return a typed answer — a probability, a pick from a list, or a score — in a single forward pass instead of generating free text. OpenAI's Decisions API is the reference: three call types (probability that a condition is true, pick from a list, score against levels), runs on GPT-6 Luna, costs $0.10/M input tokens with *zero output charge*, and is reportedly up to 10x faster. Microsoft-Decision-1, Perplexity pplx-decider-v1.1-27b (94.5% accuracy on Decision Bench at $0.017/1K decisions), Cloudflare clef-omni (audio/video/image/text), and Liquid d1 on Vercel AI Gateway all launched the same day. TypeSafe, the company behind "Jev" (the format everyone benchmarks against), announced a $7.5B valuation three weeks after launch after reportedly crossing $100M ARR in its first week. Unsloth dropped a free notebook to turn Qwen3.5-4B into a decision model on 8GB VRAM; accuracy went from 37% to 65% in ~10 minutes.

**Why it matters:** The practical unlock here is cost architecture. LangChain reported that routing tasks to the cheapest adequate model (decision call vs. generation) cut median Open SWE cost per task by 64%. Most agent steps are yes/no routing calls, not open-ended generation — and until now, you were burning generation tokens on them anyway. This category formalizes a pattern that smart builders were already doing in hacky ways. If you're building anything with agentic steps, you'll want to map which of your steps are actually decisions and route them to these.

### 2. Claude Managed Agents is in public beta — up to 1,000 sub-agents per run — and the data on whether agent teams actually pay off is in

**What it is:** Anthropic opened the Claude Managed Agents dynamic workflows beta. A lead agent writes a phased plan, fans work out to up to 1,000 agents per run, then merges results. Enabled with the `multiagent_20261001` feature flag. Claude Code Projects also fully opened to all waitlisted Pro and Max users (each project runs tasks as parallel threads, sessions can now run locally). Vals AI ran independent benchmarks of GPT-6 Sol and Opus 5.5 solo vs. in teams on Vibe Code Bench. The results are instructive: agent teams cost 1.8–5.1x more per task. Only GPT-6 Sol at medium effort improved significantly (+7.3 points). Opus 5.5 reached ~6.8 sub-agents and ~1,140 sub-agent tool calls per app at max effort with no significant gain. Separately, Prime Intellect had a swarm of 2,000+ agents rewrite their own agent runtime in Rust over two weeks — the result is 13x faster on startup and uses 83% less memory.

**Why it matters:** The Vals AI numbers are the most honest public data on multi-agent economics yet. The honest conclusion: teams are not a blanket multiplier. They help when tasks are genuinely parallelizable along architectural lines (GPT-6 Sol delegated this way naturally). They don't help much when tasks are sequential by nature. The Prime Agent rewrite shows what the ceiling looks like when the problem *is* fundamentally parallel. For Mansi's audience, this is the "before you spin up an agent swarm" reality check.

### 3. xAI launched Team Bots — AI teammates that learn your company as they work

**What it is:** xAI shipped "Team Bots": shared AI agents for organizations that build up memory and context as they're used. Unlike a personal assistant, a Team Bot is visible and accessible to all team members and accumulates institutional knowledge over time. Grok Bot also got its own email address for sign-ups and scheduling, making it function more like an employee than a tool. SpaceXAI is already using it to scale customer support.

**Why it matters:** This is the clearest push yet from any lab toward "AI as a persistent team member" rather than "AI as a per-session tool." The design pattern — shared memory + shared access + organizational identity (its own email) — is meaningfully different from what everyone has been building. Combines with Devin's new ability to spawn trees of managed sub-Devins (wall time tracks the slowest branch, not the sum of all), which is the same pattern: AI moving from "answer one question" to "take a seat at the table."

**Reel angle:** "xAI just gave AI its own email address and shared memory — the 'AI as a tool' model is being replaced with 'AI as a teammate'"
