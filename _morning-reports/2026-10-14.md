## Top 3 Things Worth Paying Attention To

### 1. Anthropic Rebuilt Version Control Because Agents Broke Git
**What it is:** Anthropic grew from ~2,500 daily merges in May to 30,000+ in September — driven almost entirely by AI coding agents — and Git couldn't handle it. They built a new VCS and migrated their entire monorepo in five months.

**Why it matters:** This is the clearest signal yet that agent-scale software development isn't a future thing. It's already straining the foundational tools of how code gets built. If this is what Anthropic's internal tooling looks like, every dev shop running AI agents heavily is going to hit the same wall.

### 3. Gemini 4 Argon Is Now in Your Coding Tools — With a Reliability Catch
**What it is:** Google released Gemini 4 Argon globally — available in Cursor, Devin, and GitHub Copilot. Cursor benchmarks show it at parity with Opus 5.5 on CursorBench. Pricing is $2/$10 per million input/output tokens (introductory, doubles after Nov 30).
