### 2. Claude Code Auto Mode is now the default — and the numbers are uncomfortable
**What it is:** Anthropic made auto mode the default setting for new Claude Code sessions on Pro, Max, and Team plans as of August 14th. The announcement included a third-party eval (Trajectory Labs): 0 out of 720 indirect prompt injection attempts succeeded against Claude Fable 5, Opus 5, or Sonnet 5 running auto mode. A separate test found that only 13.6% of humans refused a "clearly dangerous command" slipped into a session — auto mode would have blocked 89% of those cases.

**Why it matters:** The usual objection to autonomous AI agents is "who's watching?" This data flips that framing: humans watching are much worse at catching dangerous actions than the AI's built-in filters. Confirmation fatigue is real — people click "OK" on autopilot. This is the core argument for why agentic AI isn't reckless; the alternative (human-in-the-loop approval of every action) was already broken. Simon Willison notes he wants more independent confirmation, especially for supply-chain-style attacks.

**Format:** Explainer

**Reel angle:** "Only 14% of humans caught the dangerous command — here's the wild data behind why AI auto-approvals are actually safer than you clicking OK"

### 3. Qwen 3.8 27B runs on your laptop — but you have to fix its default setting first
**What it is:** Alibaba's Qwen lab released Qwen 3.8 27B — an Apache 2.0 licensed, 17GB, vision-capable model that runs locally on a MacBook Pro M5 or NVIDIA DGX Spark. It's strong enough to drive coding agents (tested with the Pi harness), return accurate bounding boxes from images, and build tools from a single prompt. The catch: it defaults to `xhigh` reasoning effort, which means asking it to "draw an SVG circle" kicks off a 22,000-token reasoning trace and produces a Bauhaus animated masterpiece 8 minutes later instead of `<circle>`.

**Why it matters:** This is the clearest example yet of the local model gap closing. A year ago, running a model this capable on personal hardware was impossible. Today it's a 17GB download. The practical unlock: run it on `low` or no reasoning for most tasks and only use `xhigh` for genuinely hard problems. Simon Willison benchmarked Multi-Token Prediction (MTP) via llama.cpp and got a 72% speed boost over the LM Studio default.

**Format:** Tip

**Reel angle:** "This free 17GB model runs on your MacBook and can write code, read images, and drive agents — but you need to change one setting before you touch it"
