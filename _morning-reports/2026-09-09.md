## Top 3 Things Worth Paying Attention To

### 1. OpenAI solved a 160-year-old math problem using 10,000 AI agents
**What it is:** OpenAI's internal model — described as "significantly more capable than GPT-6 Astra" — produced a proposed proof of the Navier-Stokes Millennium problem in 88 hours, coordinating roughly 10,000 agents across ~130 billion output tokens. A separate 17-hour Lean formalization pass verified the result. Observers estimated the run cost $10M–$40M at API-equivalent pricing.

**Why it matters:** The real story isn't the math — it's that *unstructured parallel test-time compute plus orchestration is now a first-class scaling axis*, on par with pretraining. ARC-AGI costs collapsed from hundreds of thousands of dollars to tens of dollars over 18 months; this same trajectory is now expected for any task that can be parallelized across agents. The controversy around research ethics and whether AI companies can be trusted with open science is a growing subplot.

### 2. Meta launched Muse — the most security-conscious personal AI agent yet
**What it is:** Meta's Muse is an always-on, app-connected personal AI agent running in persistent isolated Linux VMs. Each Muse instance has a separate "Sentinel" that mediates all actions — secrets are never exposed directly to the agent, sensitive actions require approval. Integrations span Gmail, Calendar, Outlook, Plaid, Stripe (with agentic payment protection), Spotify, Peloton, and Meta's own properties (Instagram, Messenger, Marketplace). Usage hit 10x internal projections on day one.

**Why it matters:** Muse is the first consumer-facing personal agent that seriously addresses the security architecture question that has blocked mass adoption — how does an AI agent act on your behalf without becoming a liability? The answer (VM isolation + Sentinel + explicit approval gates) is worth understanding because it's a template the whole industry will copy. Context and access, not raw model capability, are already the bottleneck.

**Reel angle:** "Meta's Muse is the first personal AI agent with a real security architecture — here's exactly how it works and why it matters for the whole space"

### 3. The agent harness is beating the model again — now with receipts
**What it is:** Harvey AI published results from their M&A diligence agent built with Baseten. The core finding: switching from a standard tool loop to a recursive language model (RLM) harness — a root agent that searches a data room and delegates to sub-agents — raised benchmark pass rate from 23% to 62% across models. Then self-distilled fine-tuning inside the harness pushed a single model from 46% to 60%; GRPO training on another model lifted pass rate from 30% to 63% and document coverage from 62% to 96%.

**Why it matters:** This is the most quantified version yet of the "scaffold beats the model" argument. Orchestration design and targeted post-training inside the harness now account for more performance gain than frontier model selection. LangChain shipped complementary primitives this week — subagent context forking and managed OAuth flows — signaling the stack is maturing for long-horizon agentic work.

**Format:** Shift

**Reel angle:** "A law firm published the receipts: the right agent architecture beats the frontier model — 23% → 62% pass rate just from changing the scaffold"
