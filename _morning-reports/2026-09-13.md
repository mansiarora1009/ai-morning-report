## Top 3 Things Worth Paying Attention To

### 1. Cursor Projects — Coding agents just got persistent memory
**What it is:** Cursor launched "Projects" — persistent threads with a coordinator agent, shared memory and artifacts across subagents, synced across devices and agent computers. This is a move away from "one chat per task" toward a long-lived software project substrate.

**Why it matters to your audience:** Every serious AI coding user has hit the wall where context resets kill momentum. Projects is the industry's clearest answer yet: agents that accumulate state over time, not just within a session. Claude Code's pane pop-outs and managed-agent auto mode are doing the same thing from a different direction. The convergence is real — persistent context, inspectable sessions, explicit orchestration controls. This is where agents are going.

**Format:** Shift

**Reel angle:** *"Every AI coding tool is making the same bet right now — and Cursor just showed us where agents are actually going"*

### 2. DeepSeek V4.1-Flash — The model they should have called V5
**What it is:** DeepSeek dropped a massively-undersold model: 763B total params but only 8B active on input and 16B on output (novel causal Encoder-Decoder architecture), 1M context, vision input, MIT license, $0.30/1M input tokens. KV-cache footprint is 1/8th of V4 Flash (~890 bytes/token). Runs on an M5 Max MacBook via SSD streaming. Multiple researchers said it should have been called V5, not V4.1.

**Why it matters to your audience:** The "active params vs. total params" gap is the real story — this is why the model is both cheaper and faster than V4 Pro while beating it on evals. It was designed from the ground up for long-running agents (low KV-cache = affordable context). Anyone paying for API calls for agentic workflows should be paying attention to this.

**Format:** Explainer (active vs. total parameters, KV-cache, why it matters for agentic cost)

**Reel angle:** *"They called it V4.1-Flash. Researchers say it should have been V5. Here's why the benchmarks are hiding the real story."*
