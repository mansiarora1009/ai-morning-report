## Top 3 Things Worth Paying Attention To

### 1. Coding agents are becoming infrastructure, not chat — and Cursor just went all-in
**What:** Cursor shipped Composer 2.5 and cloud dev environments for agents, and separately confirmed it is training its own frontier model from scratch using 10× more compute on xAI's Colossus 2 (a million H100-equivalents). Anthropic simultaneously published Claude Code best practices for large codebases and shipped **auto mode** — a safer way to skip permission prompts so agents can run uninterrupted. Across Anthropic, OpenAI (Codex remote execution), and Cognition (Devin Auto-Triage as an always-on bug responder), the pattern is identical: less "chat with an AI assistant," more persistent automation wired to memory, traces, and evals.
**Why it matters:** The tooling stack for software is quietly converging on a model where AI isn't a collaborator you invoke — it's infrastructure that runs in the background. Cursor training its own model is the strongest signal yet that the incumbents aren't just building on top of frontier models; they're becoming frontier labs themselves.

### 2. Anthropic acquired Stainless — and it's not about the product
**What:** Anthropic acquired Stainless, a company best known for auto-generating polished SDKs from OpenAPI specs. Anthropic already used Stainless to generate its own client libraries. The acquisition brings that capability in-house.
**Why it matters:** This is a vertical integration play for the API layer. When the company building the model also controls how developers interface with it, the SDK stops being an afterthought. For anyone building Claude-powered tools: the developer experience of the Anthropic API is about to get a lot more intentional. The bigger "what changed really": Anthropic is quietly becoming a full-stack developer platform, not just a model provider.
**Format:** Shift
**Reel angle:** "Anthropic just bought the company that makes their SDK. Here's what it signals."

### 3. Ask Claude for HTML, not Markdown — Simon Willison's most underrated tip
**What:** In a PyCon US 2026 lightning talk writeup, Simon Willison shares that asking AI tools to respond in HTML (instead of Markdown) unlocks SVG diagrams, interactive widgets, and in-page navigation in the output. He says this has made him "reconsider" his longstanding Markdown default for ad-hoc outputs.
**Why it matters:** Most people never change the default output format. HTML isn't just cosmetically different — it gives Claude a richer output channel. An explanation with an inline SVG diagram or interactive element is genuinely more useful than a wall of bullet points. This is a zero-effort change anyone can try today.
**Format:** Tip
**Reel angle:** "Try this: ask Claude to explain something in HTML. The output is not what you expect."
