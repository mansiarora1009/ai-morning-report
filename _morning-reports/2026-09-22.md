## Top 3 Things Worth Paying Attention To

### 1. Jev / Decision Models — a new shape of LLM takes over the timeline
**What it is:** TypeSafe AI's Jev model takes unstructured text in and returns typed probabilistic outputs — yes/no confidence scores, category choices, numeric ratings — instead of text. No output tokens, only input billed at $0.042/M (cheaper than GPT-5 Nano). The launch video hit ~40M views, with open-source recreations (Kev, SemIf) and a JevBench benchmark appearing within days.

**Why it matters:** This is the first credible new LLM *shape* since chat. For routing, spam filtering, reranking, tool selection, trace scoring, and supervision inside agent loops, you don't need a text response — you need a fast, cheap decision with a confidence score. Karpathy called it "no thinking, single token, low latency acceptable intelligence." LangChain already added Jev-as-judge to LangSmith. One practitioner retagged 2,300 papers in 83 seconds for $0.14.

**Format:** Explainer — "Why the next big AI model doesn't talk back"
**Reel angle:** *"What if AI could just decide, instead of explain itself?"* — show the API call, show the 0–1 confidence score output, contrast with a normal LLM response.

### 2. OpenAI has agents writing GPU kernels and running its own training experiments
**What it is:** A widely shared report describes OpenAI having largely automated parts of training experimental models — internal agents collaborate on GPU kernel writing, code optimization, and run experiments, compressing timelines from years to roughly a week for some experiments.

**Why it matters:** This is the "what changed really" inflection. The bottleneck to building better AI is no longer human researchers writing CUDA — it's the ability to evaluate and direct AI doing that work. The humans are now running the loop, not writing the code. This is recursive AI improvement in a real production context, not a research paper.

**Format:** Shift — "AI is now helping build better AI, and it's not theoretical anymore"
**Reel angle:** *"OpenAI's newest models were partially designed by their older models"* — walk through what that loop actually looks like.

### 3. Xiaomi MiMo-V2.6-Pro: frontier open-weights model trained for $3M via RL
**What it is:** Xiaomi (yes, the phone maker) released MiMo-V2.6-Pro: 1T total / 42B active params, MIT license, top score on Artificial Analysis Intelligence Index for open weights, trained with 130 GPU-hours and $2.6M in RL compute. Full training code, RL environments, and ~7K tasks to be open-sourced.

**Why it matters:** The cost to reach frontier-adjacent quality via post-training RL is collapsing. If you had $3M and a good open base model, you could build this. The open-source RL training stack (JAX + TPU, "mostly a config change to scale") is becoming as strategically important as pretraining data was 2 years ago. Multiple Chinese labs (Kimi, Qwen, DeepSeek, Xiaomi) are shipping credible frontier MoEs in a ~10-week burst.

**Format:** Shift — "The cost to build a frontier AI model just fell off a cliff"
**Reel angle:** *"$3 million, 130 hours, and now it's the best open AI model in the world"* — explain what RL post-training actually is and why it changes the economics.
