### 2. Cursor Design Mode: You Can Now Draw on Your Screen to Direct an AI Agent

**What it is:** Cursor launched Design Mode with visual prompts on June 5. Instead of typing a description of what to change, you can: select an element (pulls in the code behind it + surrounding layout), draw over the interface (circle a region, box in an area), or use voice. You can queue multiple edits and fire them off to parallel agents while previous ones are still running.

**Why it matters:** This is the first major AI coding tool to make visual context — not just code context — the primary input. The instruction is no longer just a sentence; it's the selected element + its code + layout relationships + your drawing. It dramatically reduces the translation tax of describing UI changes in words.

**Format:** First Step

**Reel angle:** *"Stop describing UI changes in words — Cursor lets you draw on your screen and the agent figures out the rest."*

### 3. What Cursor Learned Building Cloud Agents: The AI Isn't the Hard Part

**What it is:** Cursor published a post-mortem on a year of cloud agents (June 2). The biggest lesson: **the dev environment is the bottleneck, not the model.** Locally, agents inherit your working environment automatically. In the cloud, you have to reconstruct everything from scratch — and it's hard to know when you haven't done it perfectly. They also moved from "eternal" agent workflows to short-lived single-task workflows, decoupled agent loop/machine state/conversation state, and now run 50M+ agent actions/day across 7M+ workflows on Temporal.

**Why it matters:** This applies far beyond Cursor. Anyone building or evaluating AI agents needs to understand: reliability infrastructure is the actual moat, not model quality. The same model behaves completely differently depending on the scaffolding around it.

**Format:** Explainer

**Reel angle:** *"Why your AI agent works on your laptop but breaks in the cloud — Cursor ran 50 million agent actions to figure it out."*
