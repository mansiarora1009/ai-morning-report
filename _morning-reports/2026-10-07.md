### 2. Claude Code now has Mods — TypeScript plugins that rewrite its own behavior
**What it is:** Anthropic shipped Claude Code 2.1.287 with "mods" — small JS/TypeScript modules that operate at three levels: rewriting default prompts/behavior, adding new commands and workflows, and drawing custom UI. Distributed via the plugin marketplace (`/plugin install mod-name@org`). A built-in "You should know" mod flags things you or Claude might miss.

**Why it matters to your audience:** This moves Claude Code from a tool you use to a tool you customize and share. Teams can package their code review habits, safety checks, or workflow patterns as a mod. It's the "make it yours" unlock.

**Format:** First Step — gets Claude Code power users to actually build their first mod

### 3. "Decision models" just became a real product category
**What it is:** OpenAI launched the Decisions API (public beta on GPT-6 Luna) — returns predicates, choices or scores, up to 10x faster than the Responses API, $0.10/M input with no output charges. Same day, Perplexity released pplx-decider-v1.1-27b as open weights at $0.02/M, topping the HF Decision Index. A sub-category of AI that classifies, routes, and decides — not generates.

**Why it matters to your audience:** Most AI workflows are bottlenecked on over-using full-capability models. This formalizes the idea of routing the "is this X?" questions to a specialized, much cheaper, much faster model. Changes how you architect anything with conditional logic.

**Format:** Explainer — makes "routing" finally make sense as a concept

**Reel angle:** "Why you might stop using the full AI model for 80% of your actual AI calls."
