## Top 3 Things Worth Paying Attention To

### 1. Death of Parameters — The New Post-Training Scaling Law
**What it is:** Z.ai CEO Jie Tang (GLM) is making the case that parameter count is no longer a meaningful single metric. The real knobs: how much data you have, where you spend inference compute, who runs the model, and how much post-training RL has been applied. GLM-5.3 reportedly improved substantially over GLM-5.2 using the *same base architecture* — gains came entirely from one month of RL on long-horizon production environments.

**Why it matters:** Your audience evaluates models by "7B vs 70B" shorthand. This reframe changes what to ask: not "how big?" but "how much RL training, on what environments?"

**Format:** Explainer

**Reel angle:** *"Why '7B parameters' is becoming meaningless — and what to ask instead"*

### 2. The Harness Is Now the Product
**What it is:** Multiple signals point to the session/environment/memory/tools layer — not the model itself — becoming the main source of differentiation. DeepSeek Harness (everything is a plugin, 100+ user plugins in beta week one). TrueForge (MIT-licensed, self-hostable, matched Claude Managed Agents on Opus 4.8 using 30% fewer tokens; routing to GLM-5.2 cut cost 75%). Microsoft Agent Lightning: connects any harness to RL with ~6K training examples, moved Qwen3.5-9B on SWE-Bench from 41.8% → 56.4%.

**Why it matters:** The shift from "which model?" to "which harness?" is happening now. People who understand this will make very different product and tooling decisions.

**Format:** Shift

**Reel angle:** *"The AI wrapper is dead — long live the harness"*

### 3. OpenRouter Joins Stripe
**What it is:** Stripe confirmed acquiring OpenRouter, the token routing/marketplace layer that lets developers route requests across models based on cost, latency, and capability.

**Why it matters:** This isn't just an acquisition — it's a signal that token routing is becoming core payments/financial infrastructure, not a developer convenience. Stripe is betting the model-agnostic routing layer is as important as payment rails.
