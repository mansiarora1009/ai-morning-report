## Top 3 Things Worth Paying Attention To

### 1. Loopcraft: You're still prompting. The people beating you are writing loops.
**What it is:** A convergent idea surfacing from Karpathy, Steipete, and Boris Cherny simultaneously: the next-level move isn't better prompts — it's designing autonomous loops that run agents without you as the bottleneck. Karpathy: *"I don't want to be the researcher in the loop. I'm holding the system back."* Boris: *"I don't prompt Claude anymore. I write loops, the loops do the work."*

**Why it matters:** This is the clearest articulation yet of the gap between people who use AI and people who *work with* AI at scale. Stacking loops = the new compounding skill. The AI News essay introduces a "Salty Lesson": don't fix things yourself — build systems that scale with more agents.

**Format:** **Shift** — this reframes how people think about their role when using AI tools.

**Reel angle:** *"Everyone's learning to prompt better. The people winning are designing loops."*

### 2. Claude Fable 5 — and why Anthropic is sitting on a more powerful model
**What it is:** Anthropic launched Fable 5. It's a big step up from Opus 4.8, but the real story is what's *not* released: Mythos 5, which Anthropic says poses significant cybersecurity risks and is only available to vetted partners. Fable is deliberately the "safer" version.

**Why it matters:** This is the first time a major lab has publicly acknowledged holding back a frontier model on safety grounds while releasing a restricted version. It raises the question: how much capability is already being throttled before it reaches you?

**Format:** **Explainer** — unpacks what the Fable/Mythos split actually means and why it should change how people think about frontier model access.

### 3. Cursor's Agent Autonomy Auto-review — governance for agentic coding
**What it is:** Cursor shipped "Auto-review," a feature that governs how much autonomy your AI coding agent gets. You define review checkpoints; the agent pauses and surfaces changes before proceeding past a threshold.

**Why it matters:** This is a workflow design shift, not just a feature drop. As agents take longer multi-step actions, the skill of *designing checkpoints* — knowing when to let the agent run vs. when to stay in the loop — is becoming core. Cursor is building UI around this instinct.

**Format:** **First Step** — gets someone who runs Cursor agents but feels anxious about unsupervised runs to actually configure autonomy rules.

**Reel angle:** *"You can let Cursor's agent run — but here's how you set the guardrails so it doesn't surprise you."*
