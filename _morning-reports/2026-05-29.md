## Top 3 Things Worth Paying Attention To

### 1. Dynamic Workflows: Claude Code Now Orchestrates Hundreds of Agents Simultaneously
**What it is:** Anthropic shipped Dynamic Workflows (research preview) — include the word "workflow" in your Claude Code prompt and it autonomously writes an orchestration plan, then spawns hundreds of parallel subagents to tackle the task. The demo: Bun's entire codebase (750,000 lines of Zig) was ported to Rust in 11 days, 99.8% of test suite passing, using hundreds of parallel agents with two reviewers per file.

**Why it matters:** This changes the mental model from "Claude as a smart coding assistant" to "Claude as an engineering manager parallelizing work across a team of agents." The new constraint isn't intelligence — it's quota and cost (teams are hitting quota in seconds, burning $1,000–$5,000/month per engineer on agent infrastructure). Available on Max, Team, Enterprise, API, Bedrock, Vertex, and Foundry.

**Format:** First Step — the audience knows Claude Code exists but hasn't thought of it as an orchestrator. Getting them to actually try it is the move.

**Reel angle:** "One word unlocks a totally different mode in Claude Code — here's what actually happens when you type 'workflow.'"

### 2. Spec-to-PR Is Real, and PMs Are Already Shipping Code via Slack
**What it is:** Per Cognition's Walden Yan (Devin) on Latent Space: "From a specification to a completed pull request — with very little friction." Cognition's own repos went from Devin authoring 16% of commits in January 2025 to 80% in March 2026 — while engineering headcount grew only ~10%. More striking: some PMs have stopped filing tickets entirely. They prompt through Slack; the PR appears. "The PM is not creating an issue anymore. The PM is just prompting through Slack, and the pull request is then being created."

**Why it matters:** The bottleneck in software teams just shifted from writing code to writing specs. The question "do I need to be in the weeds with my IDE?" is now being answered at scale with hard data. This is the workflow shift your audience needs to understand before it reorganizes their teams without them noticing.

**Format:** Shift — a bigger pattern changing how people work with AI, backed by real production numbers.

**Reel angle:** "She stopped filing tickets. Now she prompts Slack. A PR shows up. That's the job now."

### 3. Opus 4.8's Real Improvement: It Gets Smarter by Saying "I Don't Know" More
**What it is:** Anthropic described Opus 4.8 as "a modest but tangible improvement" — refreshingly honest framing. The actual behavioral change: it abstains when uncertain rather than hallucinating. Per the system card: "Opus 4.8 had the lowest incorrect-rate of the six models on every benchmark — it achieved this mainly by abstaining on questions about which it was uncertain rather than by answering more questions correctly." It's approximately 4x less likely than 4.7 to let code flaws pass unremarked.

**Why it matters:** Most people assume better AI = more confident AI. This inverts that. Calibrated uncertainty is the harder, more useful property — and this is exactly why it feels "less lazy." Two practical additions: mid-conversation system messages (inject updated instructions without resetting prompt cache — major cost saver in agentic loops), and prompt cache minimum dropped from 4,096 to 1,024 tokens.

**Format:** Explainer — the counterintuitive insight that better AI says "I don't know" more often is worth explaining to an audience that uses AI daily but hasn't thought about this.

**Reel angle:** "Better AI doesn't mean more confident AI. Here's the counterintuitive thing Anthropic actually fixed."
