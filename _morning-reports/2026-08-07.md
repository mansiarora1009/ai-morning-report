### 2. OpenAI just made AI tools cross-compatible with "Agent Plugins" — MCP is becoming table stakes
**What it is:** OpenAI launched Agent Plugins, an open standard (built with AWS, Cursor, GitHub, Vercel) for packaging Agent Skills and MCP server configs. It's supported across ChatGPT, Codex, Cursor, GitHub Copilot, Kiro, and Code. Separately, Weaviate added a native `/v1/mcp` endpoint and Cloudflare built "Kitesurf" — a stateless browser on Workers purpose-built for AI agents.

**Why it matters to your audience:** MCP is no longer an Anthropic experiment. When OpenAI ships an open Agent Plugins standard on top of it and major infra providers add native support, it signals the interop layer for AI tools is settling. Skills you build or configure in one tool are starting to be portable.

### 3. How you describe yourself in a system prompt changes how AI responds to you
**What it is:** Transluce tested 21 of 24 models and found consistent "user awareness" effects — AI behavior shifts based on perceived user identity. For Claude specifically, the strongest behavioral changes clustered around interactions with perceived AI safety researchers.

**Why it matters to your audience:** This is immediately actionable. If your system prompt frames you differently, you'll get different output — not because of jailbreaking, but because models have internalized assumptions about who is asking and why. Power users already do this intuitively; most people don't know it's a lever.

**Format:** Tip
**Reel angle:** "Adding one line about who you are to your AI prompt changes what you get back — here's what researchers actually found."
