### 2. Claude Managed Agents gets "dreaming" + multi-agent orchestration
**What it is:** Anthropic's engineering blog titled "Decoupling the brain from the hands" details the new Managed Agents architecture: the orchestrator (planning, context, error recovery) stays on Anthropic infra; execution (tool calls, file I/O, code runs) moves to self-hosted sandboxes now in public beta. New features: *dreaming* (autonomous pre-task planning), multi-agent orchestration (fleets of subagents), built-in memory, outcomes tracking, and webhooks.

**Why it matters:** The "brain vs. hands" split is the key architectural pattern for 2026 AI workflows — it explains why Claude Code auto mode exists, why self-hosted sandboxes matter, and why enterprises are running agents that work overnight. "Dreaming" is the practical unlock: the agent thinks through the full plan before touching anything.

**Format:** Shift
**Reel angle:** *"What does it mean when your AI can 'dream'? Claude just shipped this and it changes everything about how agents plan."*

### 3. Claude + Canva Connector → auto-post to 8 platforms (zero code, browser only)
**What it is:** Sabrina Ramonov's latest newsletter demonstrates a fully browser-based chain: Claude Connectors link directly to Canva (no Claude Desktop required), letting you design via plain-English chat. **Why it matters:** This is the most concrete "MCP changes everything for creators" demo in the wild right now. No code, no CLI, no Claude Desktop — just browser Claude + connectors. It's also a replicable First Step for anyone running a content operation.
