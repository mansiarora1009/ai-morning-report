## Top 3 Things Worth Paying Attention To

### 1. Harness quality now outpredicts raw model capability
**What it is:** New research on Effective Feedback Compute (EFC) claims it reaches R² up to 0.99 in predicting agent success — while raw model size and token counts explain almost nothing. LangChain's Deep Agents v0.6 is operationalizing this: harness profiles (the prompts, tools, feedback loops around a model) are now first-class objects, letting cheaper models (Qwen, Kimi, DeepSeek) match frontier performance at 20x+ lower cost.

**Why it matters:** Your audience still debates "which model is best." This reframes the question entirely — the scaffolding is the product. Picking GPT-4o vs. Claude is secondary to how you've set up the loop.
