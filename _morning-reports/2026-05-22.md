# Morning Report — 2026-05-22

## Top 3 Things Worth Paying Attention To

### 1. AI Agents Are Not SaaS — the frame that changes how you build and buy
**What it is:** This Week in AI Club published a piece reframing the entire agent conversation. Core thesis: agents are operational infrastructure (like payroll systems), not software products. Value accrues from embedded workflow dependency and proprietary context — not from model capability, which is commoditising fast. They map a five-layer taxonomy by organisational complexity: L1 personal agents (replicable, become features), up to L5 cross-org agentic platforms (deepest lock-in, strongest business model). The "Goldilocks zone" for where agents actually create durable businesses: non-core operational departments (ops, support, marketing ops) that run repetitive workflows but aren't strategic enough to build internally. Key line: "SaaS primarily reduced software friction. Agents reduce coordination friction."

**Why it matters:** Most people in tech are still asking "which agent tool should I use?" This piece resets that to "what problem is coordination-heavy and complex enough to justify automation, but not so strategic that someone will build it in-house?" That's a different — and more useful — question. For your audience, this is the conceptual unlock for moving beyond chatbots.

**Format:** Shift

**Reel angle:** "Everyone's asking which AI agent to build — the people actually shipping them figured out that's the wrong question"

### 2. Agent scaffold beats the model — now backed by hard numbers
**What it is:** AINews surfaced new evidence for the "harness > model" thesis: a science harness boosted Gemini 3.1 Pro from 17.7 to 31.4 on a physics benchmark — surpassing GPT-5.5 Pro. When the same harness was applied to GPT-5.5 Pro, it saw no benefit. Agent design advice from @cwolferesearch: "start with single-agent systems, and only move to manager/sub-agent or decentralised multi-agent topologies when tool sprawl or prompt bloat becomes unmanageable." Weaviate shipped a built-in MCP server for hybrid BM25 + vector retrieval in coding agents without extra processes.

**Why it matters:** Still the most underrated insight in AI for practitioners. Model-switching is where most people focus their energy; scaffold design is where gains actually live. This is actionable today — you don't need to wait for the next model release.

**Format:** Explainer

**Reel angle:** "They upgraded to GPT-5.5 Pro and got nothing. Then they changed the scaffold. Here's what happened."

### 3. Google's open-source Gemini CLI dies June 18 — here's what's replacing it
**What it is:** Simon Willison flagged that the open-source Apache 2.0 TypeScript Gemini CLI stops working with Google AI subscriptions on June 18. The replacement is Antigravity — a closed-source CLI written in Go. Willison's take: "it feels like all three of the major AI labs are starting to probe the price tolerance of their API customers." Supporting data: Gemini 3.5 Flash is 3–6x more expensive than predecessor Flash models, nearly matching Gemini 3.1 Pro pricing. Separately, Google's Antigravity is being called "a usable clone of Codex/Claude Code" — but underwhelming at launch.

**Why it matters:** Developers using the Gemini CLI have a hard deadline. More broadly, the open-source-to-closed-source pivot at Google signals a monetisation inflection. Labs built open tools to grow ecosystems; now they're closing them to capture value. Expect more of this across the ecosystem through 2026.

**Format:** Shift + time-sensitive warning

**Reel angle:** "Google is killing its open-source AI CLI on June 18 — here's what's actually going on and what to do before then"
