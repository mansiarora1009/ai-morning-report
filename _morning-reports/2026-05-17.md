## Top 3 Things Worth Paying Attention To

### 1. The harness is now the product — GitHub made it official
**What it is:** The VS Code/Copilot team published a behind-the-scenes post explicitly stating that user experience is shaped by the *coding harness* — context assembly, tool use, execution loops, memory — more than by the base model alone. Simultaneously, a paper surfaced (amplified by @omarsar0 and @dair_ai) showing that grep-style text search, wrapped in the right agent harness, can match or beat embedding-based retrieval on coding-agent tasks. A concrete SDK-vs-MCP comparison found 1 step / 15k tokens (SDK) vs 4 steps / 158k tokens (real MCP server) — 8.4x token cost for identical output.

**Why it matters:** The race is no longer about model IQ. It's about orchestration: how context gets assembled, how tools are sequenced, how execution loops are structured. This is the "what changed really" take for May 2026 — the frontier is moving into the scaffolding layer, and your audience is still debating which model is smartest.

### 2. Codex is becoming infrastructure — 4M users, 1M app downloads in week 1
**What it is:** OpenAI Codex expanded to mobile. Developers are now building from iPhones while Mac minis run sessions in the background, treating laptops as "satellite devices." Adoption numbers: 4M+ weekly active users, 5x more messages per user vs. prior baseline, 1M+ app downloads in the first week. The ecosystem is plugging in fast: Ollama added local/open-model support via Codex, Zed added ChatGPT subscription access in its agent, and third-party extensions (including a native canvas called MagicPath) are appearing inside Codex.

**Why it matters:** This is a surface-area shift. Coding agents are no longer desktop IDE features — they're becoming ambient infrastructure you ping from anywhere. The "locked use" capability (Mac control while the machine is locked) signals we're moving toward always-on sessions, not discrete chat turns. For your audience: this changes where and how they build, not just what they build with.

### 3. The "AI is making me dumb" moment — and what to do instead
**What it is:** Two simultaneous signals converged this week. A Hacker News thread titled "AI is making me dumb" went top-10, with developers noting that 90–95% of Claude-generated code works but is overly verbose — and their ability to write from scratch is atrophying. On the same day, Ruben's newsletter (600k subscribers) published a detailed 5-step methodology for using Claude without outsourcing your brain: (1) give 4x more context upfront — audience, stakes, format, walkaway; (2) ask for the thing once, cleanly; (3) treat the first output like an intern draft and roast it; (4) do 40+ follow-up turns, not 2, using voice (Wispr Flow); (5) read the whole thing aloud before shipping. He uses Claude Cowork + Research + Opus 4.7 with Adaptive Thinking, and AskUserQuestion to flip the dynamic so Claude asks *you* questions.

**Why it matters:** The AI-native community is now actively building frameworks to avoid cognitive atrophy. This is the same moment that happened with GPS (you stopped remembering directions) and autocorrect (you stopped knowing how to spell). The people ahead of the curve are developing deliberate practices around it. Your audience needs to hear this before they feel it.
