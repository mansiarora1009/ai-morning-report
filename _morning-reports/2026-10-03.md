## Top 3 Things Worth Paying Attention To

### 1. Airbnb's "code is the artifact" shift — what AI-native actually looks like at scale

**What it is:** Ahmad Al-Dahle (former head of Meta's Llama models, now Airbnb CTO) gave Latent Space a detailed look inside Airbnb's AI transformation. Numbers: 60% of code is AI-authored, 80% more features and improvements shipped YoY, PR throughput up ~1.6x per engineer. The process change: product, design, and engineering teams skip directly to working with prototypes instead of handoff artifacts. "We moved away from excessive artifact generation to the code being the artifact that we reason upon." The next stage: async agents automating on-call — when a Grafana alert trips, an agent spins up, triages, proposes a PR fix, and may close the incident itself if it determines the alert was flaky. Human reviews the PR after. Al-Dahle's prediction: "large amounts of asynchronous agents helping automate and manage the marketplace."

**Why it matters:** This is the clearest ground-level account of what changes when a large company actually commits to AI-native development — not the benchmark story, not the "AI will replace engineers" story, but the specific organizational and workflow changes that unlock the output gains. The "code is the artifact" reframe is one most engineers haven't made yet but will need to. And the async on-call agent pattern is the most concrete "agents doing agentic work in production" example that's been publicly documented at company scale.

### 2. Pi Durable: the agent harness problem just got a serious answer

**What it is:** Pi 1.0 (Earendil's minimalist agent harness) went stable, and Pi Durable simultaneously launched a TypeScript port that externalizes all stateful components. Key capabilities: crash survival (every step checkpointed, agents automatically resume from exact state after failure or restart); portability (runs on any JS runtime — Node, Bun, Cloudflare — with pluggable storage: Memory, SQLite, JSONL); concurrency (a single harness runs multiple parallel, branching conversations without blocking); hot-swapping (tool and extension code updated dynamically while the agent is running); and multiplayer state sync (app state stored alongside transcripts, multiple users or UIs steer the same agent simultaneously). Also shipped: native MCP and Jev support, deferred tool loading, cache warming for Anthropic models, mid-conversation system messages.

**Why it matters:** The single biggest practical problem with AI agents in production isn't model quality — it's reliability. Agents crash, lose state, can't resume. Pi Durable directly solves that. The TypeScript release is a signal too: harness engineering is becoming a first-class discipline, and the ecosystem is now building durable infrastructure around it, not just inference wrappers. For anyone who's tried to run multi-step agents and had them fail halfway, this is the practical unlock.

**Format:** Explainer

**Reel angle:** "AI agents crash and you lose all the work — there's now a stable framework that checkpoints every step and automatically resumes from where it failed"

### 3. Cursor Rollouts + Security Reviewer: bots watching your code before and after it ships

**What it is:** Cursor shipped two production bots on Sept 23. Rollouts: when a PR opens, it reads the diff and the systems it touches, writes a monitoring plan (risks, expected effects, signals to check, instrumentation gaps) as a PR comment, then watches the deployment from PR to production and flags regressions. Security Reviewer: runs on every PR, reads the change in the context of the whole codebase, reports vulnerabilities with explanation and proposed fix. Security Reviewer reduced average review time from 4.8 to 3.8 minutes and increased comment acceptance from ~47% to ~65%. Both on Teams and Enterprise plans.

**Why it matters:** This is the "last mile" of AI-assisted development — not writing code, but making sure code that ships doesn't break things. Most AI coding tools stop at merge. Rollouts and Security Reviewer extend the loop into deployment monitoring and security auditing. The fact that Cursor is building production monitoring (not just coding assistance) signals where IDE-native AI is headed: from "help you write" to "watch what happens when it runs."

**Format:** First Step

**Reel angle:** "Cursor now ships two bots that watch your code after it deploys and review it for security before it merges — here's what they actually do"
