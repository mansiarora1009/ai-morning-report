### 2. OpenAI built a Jev competitor in one week — and what it is reveals everything about where agent stacks are going

**What it is:** Jev (the startup decision model that went viral for ultra-fast structured output) launched, and OpenAI's inference team built a direct competitor in one week: the Decisions API. The key detail most people missed in the DevDay coverage: this is **not a new model**. It's the same Luna weights, constrained with structured output, optimized for time-to-first-decision (TTFD), and run in parallel for batched questions. OpenAI's API product lead Nikunj Handa on Latent Space: "We zero-shot this on top of Luna to see how it goes." It is specifically useful for: fast classification (support ticket routing), snappy tool-calling in voice interfaces (GPT Live), and any place you need sub-second yes/no or multi-choice decisions from a frontier model.

**Why it matters:** The Decisions API is a pattern signal, not just a product announcement. The pattern: for an agent that needs to make lots of small, fast decisions, you don't always want the full reasoning model — you want something that returns a structured answer in milliseconds. This is how you make agents feel less like "waiting for an AI" and more like "software that works." The fact that OpenAI cloned it in a week also signals they see this as a critical API primitive — it's going to be the routing layer inside every multi-step agent.

### 3. Meta's Context Language Models: treating your agent's memory as an editable document, not an endless scroll

**What it is:** Meta Research (from AINews Sep 29-30 coverage) introduced Context Language Models (CLMs), which treat context as an editable file rather than an append-only log. Current models can only add to context — every tool call, every response, every observation piles up until the window fills. CLMs instead learn context-management policies directly in the weights: when to compress, what to forget, what to preserve — no external harness needed. Result: 65% higher performance with the same compute on a 24-hour multi-repository agent swarm task compared to standard append-only context models.

**Why it matters:** This is the research answer to the most common complaint about long-running AI agents: "it gets dumber as the session gets longer." The append-only context model isn't a bug — it's a fundamental architectural assumption baked into every current model. CLMs change that assumption. OpenAI is working toward this from the product side (compaction, /compact, cache pre-warming), but CLMs would bake the policy into the model itself. For anyone building multi-hour or multi-day agent workflows, this is the single most important research signal of the week.

**Format:** Explainer

**Reel angle:** "Meta research: the reason your AI agent gets worse over a long session — and the model design that fixes it"
