## Top 3 Things Worth Paying Attention To

### 1. Your Claude Code sessions might not be as private as you think
**What it is:** Researchers disclosed a vulnerability across all three major frontier APIs (Claude, GPT, Gemini): their "encrypted" reasoning traces can be decoded via a replay attack — take a signed thinking block from one API response, inject it into a request to a weaker model, and repeatedly sample until it transcribes the hidden thoughts. In a scan of ~7,000 public traces, they recovered 62 API keys, 33 email addresses, and 33 passwords — 64 of which appeared *only* inside reasoning blocks and nowhere in the visible session. Multiple vulnerabilities were already fixed, but similar attacks remain possible.

**Why it matters:** Anyone who has shared a Claude Code session publicly — GitHub, YouTube, a blog post — may have exposed their inner reasoning to anyone with this technique. It reframes a core assumption about "extended thinking" products: the hidden chain-of-thought isn't a secure vault. It also crystallizes a bigger monitoring problem: even if labs hide reasoning, decoded CoT often comes out terse, multilingual, or "neuralese" — not human-readable, not auditable.

### 2. Meta Muse Glimmer — local frontier AI is genuinely here
**What it is:** Meta released Muse Glimmer 30B under Apache 2.0: a dense multimodal model built for always-on local agent loops, with controllable reasoning, tool use, and 100+ language support. At 4-bit quantization it fits under 20GB — early community tests confirm it runs on a single RTX 3090 (24GB VRAM) at 64–124 tok/s with 256K context and a DFlash speculative drafter. It was logit-distilled from Muse Spark and trained from the outset on agentic traces, not a conventional base model. Muse Spark 1.2 open weights are also coming soon. Community consensus after 24 hours: strongest model for its weight class on agentic workflows and tool calling, slightly behind on raw coding.

**Why it matters:** "You need a data center to run a frontier agent" just quietly stopped being true. A 30B model that handles tool calls, multimodal input, and 256K context on consumer hardware changes the cost equation for anyone building private, local AI workflows — no API keys, no rate limits, no data leaving your machine. Qwen 3.8-27B is also expected this week, so the 24–32GB GPU tier is about to get very competitive.

**Format:** First Step

**Reel angle:** "Meta just dropped a free, open model that runs on a single gaming GPU — here's how to actually set it up for local AI agents"

### 3. Grok Bot: the persistent AI coworker UX just shipped
**What it is:** xAI launched Grok Bot beta — AI agents with their own cloud computers that can sign into tools and do persistent, scheduled work. Key product details: bots watch Slack threads and GitHub Actions, repeat scheduled routines, create and manage other bots, and operate across linked cloud environments. They're designed around Cursor integration and priced accordingly. It's closer to a "hire an agent" UX than a chatbot.

**Why it matters:** This is the first major product from a frontier lab where the default is "the AI works while you're offline" rather than "you prompt, it responds." The feature list (watches Slack, monitors GitHub, spawns sub-agents, maintains persistent context) maps almost exactly to the tasks knowledge workers delegate to junior hires. The behavioral shift worth a reel: AI is moving from a tool you use to a system that runs.
