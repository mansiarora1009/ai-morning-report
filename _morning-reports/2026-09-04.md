### 2. Anthropic Eng: Managed Agents — decoupling the brain from the hands
**What it is:** A new Anthropic Engineering post lays out how they scale managed agents in production: the core insight is separating the **reasoning model** (the "brain" that plans and decides) from the **execution layer** (the "hands" that call tools, browse, write files). The architecture lets Anthropic run many execution workers per reasoning call, swap execution models cheaply, and bound blast radius when an agent makes a mistake.

**Why it matters:** This is the architecture behind Claude Code, Cowork, and every serious enterprise agent deployment — and it's the thing your audience doesn't yet understand about how production AI agents actually work. Most people think "AI agent" = one model doing everything. The brain/hands split explains why agents fail in predictable ways and how to design around it. It's also a template for anyone building their own agent systems.

**Format:** Explainer

**Reel angle:** "Why Anthropic splits every AI agent into a 'brain' and 'hands' — and why understanding this will change how you build with AI"

### 3. Cursor + Nokia: 50M lines of code analyzed in 2 weeks
**What it is:** Nokia used Cursor to analyze over 50 million lines of legacy code in two weeks — a task that would have taken a traditional team many months. Separately, Cursor also shipped **self-hosted machines**: enterprises can now run cloud Cursor agents on their own managed infrastructure rather than Cursor's cloud, unblocking security-sensitive orgs that couldn't use cloud agents before.

**Why it matters:** Two distinct signals here. The Nokia case study is the "enterprise AI coding is real" proof point — 50M lines in two weeks is the kind of number that moves internal budgets and convinces skeptical CTOs. The self-hosted machines feature signals that the remaining blocker for regulated industries (healthcare, finance, defense) — "we can't send code to a third-party cloud" — is being actively solved. The enterprise AI coding era isn't coming; it's here.
