## Top 3 Things Worth Paying Attention To

### 1. OpenAI cuts off Cursor after SpaceX acquisition
**What it is:** After Cursor was acquired by SpaceX, OpenAI revoked their API access, citing "experience with Elon Musk's companies violating contracts." Cursor says OpenAI is only 5% of their traffic and is now leaning on Grok 4.6 and Claude.

**Why it matters:** This is the clearest sign yet that model API access is a competitive weapon. Any product built on a single model provider is one corporate dispute away from disruption. The practical winner here is Anthropic — Claude is the default coding backbone now, and the ecosystem just made that even stickier.

### 2. Persistent cloud agents are replacing local CLI agents
**What it is:** Multiple convergent moves this week — Claude Code ships `/resume` for desktop session continuity, Kimi Code adds Remote Control, OpenAI launches "appshots" for app-context grounding. Practitioners are explicitly arguing that local CLI agents are giving way to cloud-resident agents with shared context, memory, and service integrations.

**Why it matters:** The mental model of "AI assistant I chat with" is shifting to "AI agent that lives in the cloud and picks up where it left off." This changes how people architect their AI workflows and what persistence/memory even means.

**Format:** Shift

**Reel angle:** "Your AI coding agent is moving to the cloud — here's what that actually means for how you work."

### 3. Tweaking CLAUDE.md improved PR quality more than swapping models
**What it is:** Theo (T3 Code) reported that fine-tuning their `agents.md`/`CLAUDE.md` significantly improved PR quality — with the biggest gain in PR naming and descriptions, not raw code generation.

**Why it matters:** This is the "instruction layer > backbone" insight landing in a real production team. The loop around the model (task decomposition, naming instructions, verification prompts) is where the leverage is right now — not chasing the latest model. This is hugely actionable for anyone using AI coding agents.
