### 2. Flue 2 — Someone Finally Built the React for AI Agents
**What it is:** Fred Schott (creator of Astro, now at Cloudflare) shipped Flue 2, the first stable release of his agent framework. The defining feature: React-style "Agent Hooks." An agent in Flue is a JavaScript function that re-renders before every model call. Hooks like `useSkill()`, `useTool()`, `useSubagent()` let agents manage state dynamically and reconfigure themselves mid-conversation. Core thesis: *there is no agent without a harness.*

**Why it matters:** Schott's framing — "we're in the jQuery era of agents, not the React era" — is the most useful mental model for where agent development actually is. Flue is an attempt to build the composability layer that makes agents maintainable at scale, the same way React made UIs maintainable. For your audience building or evaluating agent products, this reframes what's missing when an agent feels brittle: it's not the model, it's the harness.
