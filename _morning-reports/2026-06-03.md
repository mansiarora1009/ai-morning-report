## Top 3 Things Worth Paying Attention To

### 1. Opus 4.8's real story isn't parallel agents — it's the lesson buried in the reaction
**What it is:** Claude Opus 4.8 shipped with a headliner feature: dynamic multi-agent workflows where Claude writes an orchestration script, then spins up parallel subagents to tackle complex tasks. It tops ARC-AGI-3 and triples GPT-5.5's score on that benchmark. But the most important thing that came out of the launch is a counter-take from the people actually shipping with it: "This doesn't prove loose multi-agent systems work. Deterministic workflows around small agent loops are more reliable."

**Why it matters:** The parallel-agents feature gets the press, but the practitioners' take is the real signal. Every's internal benchmark found Opus 4.8 "a big jump from 4.7, competitive with GPT-5.5 on senior-engineer tasks" — yet their note is the harness still matters more than the model. The pattern from last month ("scaffold > model") keeps getting reinforced, now by Anthropic's own flagship launch.

### 2. The "one job" test — a simple way to figure out which tools you should build instead of buy
**What it is:** Michael Crist (Substack) published a piece on rebuilding Granola ($168/year meeting transcription) from scratch using Claude Code's `/goal` command and Whisper. The build took a toilet break. But the piece's actual payload is a mental model: *"Look at a tool you pay for and ask what you really use it for. Forget the long feature list. Day to day, what is the actual job you open it for? If the honest answer is one thing, one core loop you run over and over — that tool is probably a rebuild candidate now."* His team is now rebuilding a $24,000/year BI tool.

**Why it matters:** The audience knows vibe coding is a thing. What they don't have yet is a framework for deciding *which* tools are worth rebuilding. This is that framework, and it applies to anyone paying for SaaS with one real workflow at the center. The moment is now: Claude Code's `/goal` mode (autonomous execution without confirmation prompts) makes this accessible to non-engineers.

### 3. RTX Spark + Surface Laptop Ultra: 120B model, local, on a laptop
**What it is:** NVIDIA and Microsoft announced RTX Spark — a 1-petaflop Windows superchip with up to 128GB unified memory, full CUDA/RTX support, local 120B model inference, and new Windows agent security primitives. The flagship device is the Microsoft Surface Laptop Ultra.

**Why it matters:** 120B parameters locally on a laptop-class device is a meaningful threshold. Until now, running a frontier-grade model locally required a beefy workstation or Mac Pro. The privacy implications are significant (no data leaving device) and the use cases this unlocks — offline agents, private document analysis, enterprise air-gapped environments — are concrete. This is the hardware equivalent of a model release.
