### 2. Video intelligence isn't coming from video — it's coming from language
**What it is:** Ethan He (xAI Grok Imagine lead) explained on Latent Space that "the visual intelligence comes mostly from language, not video." A video diffusion model is "kinda dumb" — it takes prompts literally. The real intelligence is a *larger* language model rewriting your sparse prompt into a rich scene description before the diffusion model runs. He also outlined the "video agent" trajectory: LLMs orchestrating diffusion models as tools, the same arc as coding (Copilot → Codex → Claude Code). He predicts video agents hit production quality (ad-distributable) by end of 2026.

**Why it matters:** Most people think video AI = better video model. The actual bet is on the orchestration layer on top of it. Same pattern as coding agents — the model is the tool, the harness is the product.

**Format:** Explainer

**Reel angle:** "Why the next Sora won't be a better video model — it'll be a video agent. Here's the architecture shift nobody's explaining."

---

### 3. The main engineering leverage in AI has moved from model calls to harness design
**What it is:** Multiple signals this week all point to the same thing. Perplexity's "Search as Code" (writing Python against a search SDK instead of iterative tool calls) improved their benchmark from 0.152 → 0.386. Google's Managed Agents spin up a full Linux sandbox with one API call. LangChain pushed agent lifecycle tooling, persistent context, and automated failure triage. NVIDIA Cosmos 3 shipped as a full-stack release — weights, code, datasets, and fine-tuning recipes together. Meanwhile, the Claude Code incident this week (rate limits reset after Opus 4.8 sessions spawned too many parallel subagents unexpectedly) made clear that coding-agent product quality is now about orchestration behavior, not raw model IQ.

**Why it matters:** If you're building AI workflows and still thinking "which model should I call?", you're optimizing the wrong thing. The delta is in how you structure the loop around the model.

**Format:** Shift

**Reel angle:** "The coding agent that keeps failing isn't using the wrong model. It's using the wrong harness. Here's what that means."
