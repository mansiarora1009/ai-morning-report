## Top 3 Things Worth Paying Attention To

### 1. Simulation is the new scaling law — swyx's framework is a must-read
**What it is:** swyx dropped a long-form essay (AINews, Aug 22) laying out an 8-stage framework: every year since 2022, one more component of the AI intelligence pipeline has flipped from human-made to model-made. Stage 1 (2022): the reward signal. Stage 2 (2023): the training data. Stage 3 (2023): the teacher. Stage 4 (2024): the curriculum. Stage 5–6 (2026): the researcher and the environment. Stage 7 (2025–26): the human subject (Simile AI is building synthetic digital twins). Stage 8 is the physical world — the one thing you can't fully simulate yet. The key insight buried at the end: the synthetic frontier doesn't advance when generation gets better — it advances when **verification** does.

**Why it matters:** This is the clearest mental model for what's actually happening in AI right now. Your audience has been hearing "AI is getting faster and cheaper" without a framework for *why*. This explains it. It also sets up every product announcement from the last two years — synthetic data, distillation, RLHF, AI researchers, digital twins — as chapters of the same story.

**Format:** Shift

**Reel angle:** "There's a pattern almost no one has named: each year, AI ate one more piece of how AI gets made. Here's all 8 stages and what's left"

### 3. GitHub agents are now living in Slack — and this is what agentic work actually looks like
**What it is:** GitHub rolled out collaborative agent workflows into Slack and Teams: you assign a task in a shared Slack channel, the agent picks it up, opens PRs, loops in design assets, and surfaces updates — all inside the channel. No browser context-switching. Devin-style async coding, but woven into existing team communication instead of requiring a separate tool.

**Why it matters:** This is the first mass-market taste of agents living *inside* workflows people already use, not in a separate tab you have to remember to check. The friction drop is real. Your audience uses Slack every day — this is how agents stop feeling like demos and start feeling like colleagues.

## Quick Scan

- **Karpathy's autoresearch (March 2026, circulating now):** Overnight agent loop ran 700 experiments on a real LLM training setup, kept 20 improvements, cut time-to-GPT-2 from 2.02 to 1.80 hours — real transferable code changes found while he slept. The ratchet loop: modify → run 5-min experiment → keep if validation loss improves → repeat.
- **Simile AI:** Digital twins of real people built from 2-hour biographical interviews reproduced those people's survey responses 85% as accurately as the people reproduced themselves two weeks later. SimGym at Shopify is already simulating shopper trajectories. Focus groups and A/B test panels are becoming inference workloads.
- **Qwen3.8-27B local agentic workflows:** Single RTX 3090, autonomously navigating university systems via Playwright + SSO cookies and processing video (download → frame extraction → Whisper transcription). The community debate: local models are now good enough for real agentic work — but permission scope is the new safety question.
- **DeepSeek V4-Flash-Vision-Exp:** Multimodal API launched, images billed up to 384 tokens at V4-Flash pricing. Broad gains over DeepSeek V4-Flash-0731 on agent benchmarks. Files API added for reusable image uploads.
- **NVIDIA AVO:** 100% on public ARC-AGI-3 environments — but Chollet's caveat: this is the tutorial/demo set, not the full benchmark. Important distinction.
- **DeepMind Recirculation:** Inference-time technique feeding deeper-layer activations back to earlier layers — no retraining needed. Reports: -60% contextualization errors, -23% perplexity, +21% GSM8K. Worth watching if it replicates.
- **OpenHands switches free default to Kimi K3** — open-source coding agent changing its backbone; costs drop for self-hosters.
- **FreeToken (UC Berkeley):** 753B GLM-5.2 at 14.9 tok/s on a single RTX PRO 6000; Qwen3.6-35B at 39.3 tok/s on an 8GB RTX 4060 laptop. 2–4x Ollama throughput claimed on consumer GPUs.
- **OpenAI adds hard spend limits:** Teams can now set monthly org/project caps by API key — useful as agentic workloads become concurrent and less predictable.
