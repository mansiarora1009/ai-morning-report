## Top 3 Things Worth Paying Attention To

### 1. The agentic loops debate is the real culture war in AI engineering right now
**What it is:** At the AI Engineer World's Fair, the central debate was whether autonomous agentic loops — AI iterating on code end-to-end without human checkpoints — are ready now or whether "the hype is outrunning the discipline." The skeptic camp argued devs need to step *down* abstraction levels first to build intuition. The data: 95% of AI engineers now use agents (up from ~50% last year), and 89% let agents *write* data to production systems — but the control layer remains mostly ad-hoc human approvals.

**Why it matters:** This isn't philosophical — 59% of respondents fear AI-generated code is creating long-term technical liabilities, and 40% say token costs regularly cap how ambitiously they use AI. The insight buried in the noise: the bottleneck isn't the agent, it's human review capacity and the ability to mentally hold what's being built.

**Reel angle:** "95% of AI engineers use agents — but nobody's solved who's actually responsible for what the agent ships"

### 2. The web is quietly splitting into human and agent experiences
**What it is:** Vercel's head of software describes their agent framework (`eve`) detecting agent requests and serving raw Markdown instead of HTML. Adobe is experimenting with "agentic sites" that assemble pages around individual user intent at request time. Vercel reports bot traffic rising while human web traffic is stagnant or declining.

**Why it matters:** The web as a medium is being redesigned — not just for SEO, but for agent consumption. Developers building products now have to think about two audiences: the human and the agent working for the human. This is the beginning of "agent-readable web design" as a distinct skill.

**Format:** Explainer

**Reel angle:** "Vercel now serves a different website to AI agents than to you — here's why that changes everything"

### 3. "Skills" are how engineers are solving the model knowledge cutoff problem without fine-tuning
**What it is:** Vercel's agent framework injects portable "skills" — on-demand context bundles — at runtime to forward-correct outdated model behavior. Real example: models still recommend deprecated APIs, so a skill updates that at inference time. It's emerging as a practical pattern for teams shipping agents against fast-moving tooling.

**Why it matters:** Fine-tuning is expensive and slow. Prompting degrades. Skills are a third option: modular, versioned, swappable knowledge injected into agent context when needed. Multiplayer agent development — how teams share and evolve skills together — is the next unsolved problem in this space.

**Format:** Explainer / First Step

**Reel angle:** "Your AI agent is using old knowledge — here's the pattern engineers use to fix that without fine-tuning"
