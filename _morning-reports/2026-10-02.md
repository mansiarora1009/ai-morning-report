## Top 3 Things Worth Paying Attention To

### 1. Pi 1.0 + Pi Durable — The Agent Harness Layer Goes Stable
**What it is:** Pi 1.0 (the minimalist agent harness) hit v1.0 with native MCP support, mid-conversation system messages, and deferred tool loading. Pi Durable is the TypeScript port that externalizes all stateful components: crash survival via checkpointed tasks, portability to any JS runtime (Node, Bun, Cloudflare), concurrent parallel conversations, hot-swapping of tool code while an agent runs, and multiplayer state sync so multiple users can steer the same agent simultaneously.

**Why it matters to your audience:** Most people building AI workflows hit the same wall — agents lose context on crashes, can't run in parallel, and require restarts from scratch. Pi Durable solves the infrastructure layer that was previously DIY. This is the "finally, production-grade agent wiring" moment.

"Dots" (agents that keep making progress between your conversations) is the behavioral shift to watch.
