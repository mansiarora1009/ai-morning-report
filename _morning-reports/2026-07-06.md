## Top 3 Things Worth Paying Attention To

### 1. Simon Willison: Have your coding agent record video demos of its work
**What it is:** Simon Willison shipped `shot-scraper video` (shot-scraper 1.10) — a new CLI command that accepts a YAML storyboard file and uses Playwright to record a polished video demo of a web app. The storyboard for his own demo was written entirely by GPT-5.5 xhigh in Codex Desktop. He also noted a broader pattern: well-written `--help` output is enough for a coding agent to use the tool without extra docs — it functions like a built-in SKILL.md.

**Why it matters:** The idea of *making your agent show its work* as a video is genuinely new territory. As AI-built features ship faster, "prove it works" becomes the bottleneck. This is a repeatable workflow for anyone shipping agent-built software. The `--help as SKILL.md` pattern is also immediately actionable for anyone building or wrapping CLI tools for agents.
