### 2. Wiki memory is the pattern replacing raw document retrieval in persistent agents
**What it is:** The emerging pattern in agentic systems isn't storing raw documents and re-retrieving them on each run — it's building a task-specific Markdown wiki layer that agents update over time, synchronized via something like FastMCP. mem0 frames this as: persistent intelligence is a memory architecture problem, not a weight-update problem.

**Why it matters to Mansi's audience:** Anyone trying to build agents that "remember" things and get smarter over time has probably hit the wall of naive RAG. This gives them a concrete mental model and architecture to replace it.

**Format: Explainer**
**Reel angle:** "Your AI agent doesn't actually remember anything between sessions. Here's the architecture pattern people are actually using to fix that."

### 3. Claude's web_fetch exfiltration bug (now patched) is a masterclass in tool permission design
**What it is:** Anthropic's Claude blocked LLMs from constructing arbitrary URLs to prevent data exfiltration — but it still followed links embedded in pages it had fetched. An attacker could host a page with letter-by-letter navigation links that extracted name, home city, and employer. Now patched: web_fetch no longer follows links in fetched content.

**Why it matters to Mansi's audience:** This is the exact kind of edge case that bites teams building agentic pipelines with real tool access. Understanding how tool permission chains create attack surfaces is a must-have mental model for anyone designing agents.

**Format: Explainer**
**Reel angle:** "A simple trick could make Claude leak your personal data through its web browser tool. Here's how prompt injection + tool chaining actually works — and how Anthropic fixed it."
