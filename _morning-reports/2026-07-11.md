## Top 3 Things Worth Paying Attention To

### 1. "The harness is the product" — and GPT-5.6 proves it
**Format: Shift**
**What it is:** OpenAI launched GPT-5.6 as three tiers (Luna/Terra/Sol). Sol doesn't just answer — it acts as orchestrator, automatically spawning subagents to plan, execute, and verify. The catch: those subagents silently inherit premium settings. Early users got cost blowouts. Perplexity's CEO framed the moment: "the real product is now the harness around it."
**Why it matters:** This reframes the entire AI power-user conversation. Raw model quality is table stakes. What differentiates outcomes now is *who understands how to configure the orchestration layer* — token usage, subagent scope, cost controls. Your audience is exactly the people who need to understand this shift before it bites them.
**Reel angle:** "GPT-5.6 can spawn its own subagents. Here's why that's quietly burning people's API budgets — and what to do about it."

### 2. GPT-5.6's Programmatic Tool Calling — the model writes its own glue code
**Format: Explainer**
**What it is:** New in the GPT-5.6 API: "Programmatic Tool Calling" — the model writes JavaScript to orchestrate its tool calls dynamically, rather than selecting from a fixed tool schema. Also: explicit prompt cache breakpoints (similar to Claude's caching system) and native multi-agent sub-agent spawning baked into the API.
**Why it matters:** Most people think of tool use as "the AI picks from a list." This flips that — the AI is now writing the wiring itself. It's a meaningful capability jump that changes what's possible in custom agents, and most devs aren't aware it exists.
**Reel angle:** "You've heard of tool use. GPT-5.6 just shipped something wilder — the model writes its own tool orchestration code. Here's what that actually means."

### 3. Claude Code desktop now has a built-in browser
**Format: Tip**

**Why it matters:** This is a genuine workflow improvement for anyone using Claude for dev work. Claude can now look things up in real time while it codes, which closes a major gap vs other AI coding tools.
