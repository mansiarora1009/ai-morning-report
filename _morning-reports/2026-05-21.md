### 2. Scaling Managed Agents: Decoupling the brain from the hands
**What it is:** Anthropic Engineering published a deep-dive on how they architected managed agents at scale. The core insight: separate the *reasoning layer* ("brain" — deciding what to do) from the *action layer* ("hands" — executing tool calls, file writes, API calls). When they're coupled in one call loop, failures cascade and debugging is a nightmare. When they're decoupled, you can retry actions without re-running expensive reasoning, swap models independently, and audit the action layer without touching the planner.

**Why it matters:** This is the architecture pattern that separates "AI demo" from "AI in production." Most people building with agents are coupling brain and hands by default because that's how the simplest code reads. This post names the problem and the fix. It's a direct answer to "why does my agent keep breaking in weird ways?"

**Format:** Explainer

**Reel angle:** "Why your AI agent keeps failing in production — the brain/hands architecture split that actually fixes it"
