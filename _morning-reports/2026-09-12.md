## Top 3 Things Worth Paying Attention To

### 1. Cursor Projects: AI coding finally has persistent memory
**What it is:** Cursor launched "Projects" — persistent threads with a coordinator agent that retains shared memory and artifacts across your agents, synced across user devices and agent computers. It's a structural shift from "one chat per coding task" to a long-lived software project substrate where agents accumulate state over time.

**Why it matters:** This is what moving beyond ChatGPT actually looks like for developers. Right now, every time you start an AI coding session you're re-explaining the project. Projects flips that: the agent remembers what it built last week. Combined with Claude Code's new managed sessions and auto mode, the market is converging on persistent, inspectable, coordinator-orchestrated agents — not just smarter completions. If your audience codes, this is the reel they need.

### 2. DeepSeek V4.1 Flash: frontier-tier AI at $0.27 a task
**What it is:** DeepSeek launched V4.1 Flash — a 763B-parameter model with a radically new causal Encoder-Decoder architecture (8B active params on input, 16B on output), 1M context, vision, MIT license, at $0.30/M input tokens. Independent benchmarks put it at #1 open-weight overall, matching GPT-6 Astra on automation benchmarks. DeepSeek is retiring V4 Pro and routing its traffic to V4.1 Flash. Total task cost: $0.27 per complex Intelligence Index task — 7x cheaper than the prior generation.

**Why it matters:** The "which model should I use" math just changed for anyone building AI workflows. A model that runs complex agentic tasks at $0.27 means you can afford to run more agents, more often, with longer context. The architecture breakthrough (890 bytes/token KV cache, down 8x) is what enables this — and you can now run it locally on an M5 Max 128GB via SSD streaming, or 300+ TPS on 4 RTX Pros. Sebastian Raschka called it "they should have named this V5."

### 3. The harness-model mismatch problem — why copying a smarter AI's reasoning makes things worse
**What it is:** A Salesforce paper (surfaced in AINews) showed that training a weaker model on a stronger model's full reasoning trajectories can *hurt* performance by 4–30 points after the harness evolves — because the fine-tuned model adopts an incompatible planning style. The fix: rewrite only the failing turn in the weaker model's own rollout, not the whole trajectory.

**Why it matters:** This is a "what changed really" take on why AI systems fail in production. The mental model most people have — "give the smaller model examples of the bigger model thinking" — is wrong in the multi-agent, evolving-harness world. The model and its scaffolding have to co-evolve. ByteDance's HarnessDev (agents that build and improve their own runnable harnesses) is the emerging answer, with 34/64 improvements transferring to held-out tasks.

**Format:** Explainer

**Reel angle:** "Why training AI on smarter AI examples actually makes it dumber — the harness-model mismatch problem explained"
