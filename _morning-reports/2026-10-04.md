## Top 3 Things Worth Paying Attention To

### 1. Airbnb's AI-native playbook is the most detailed public case study we have of what this actually looks like

**What it is:** Latent Space published an in-depth interview with Airbnb CTO Ahmad Al-Dahle (former head of generative AI at Meta, who led Llama 1–3). He's been running Airbnb's "AI-native" transformation since January 2026. The numbers: 60% of code is now AI-authored, they've shipped ~80% more features year-over-year, and average engineer PR throughput is up 1.6x. AI resolves roughly half of customer support tickets.

**Why it matters:** The real story isn't the metrics — it's the process changes behind them, which are specific and replicable. Three shifts stand out: (1) *Code as the artifact* — they eliminated PRD and Figma handoffs between product, design, and engineering, going straight to prototypes with code as the reasoning surface. (2) *The Everest context graph* — an internal system using LLMs, embeddings, and AI retrieval to make prior project learnings queryable by any team. Airport pickup (a new service) took 6 weeks; the prior grocery service had taken 8 months. The graph made the team generalists able to work on specialist parts of the codebase. (3) *Async event-triggered agents running on-call* — when a Grafana alert fires, agents spin up, triage, and can close the incident or surface a PR. This is async agents with consequences, not a chat UI. One counter-note: Al-Dahle is deliberately careful about which support tickets to *not* automate yet, and he's pushing hard to ensure engineers can explain everything AI generates — otherwise junior devs don't develop engineering judgment.

### 2. Pi 1.0 + Pi Durable: an open-source agent harness just went stable, and the TypeScript port is the more interesting story

**What it is:** Earendil's Pi framework hit 1.0 this week. Pi is a minimalist open-source agent harness — the layer that wraps the LLM loop. Pi 1.0 ships native MCP support, a "Codemode" for integrated tool use, deferred tool loading, cache warming for Anthropic models, and mid-conversation system message updates. Simultaneously, Pi Durable ported the entire harness to TypeScript and externalized all stateful components. Key Pi Durable features: crash survival (every step is checkpointed — if the process dies, agents resume from their last exact state), pluggable storage backends (Memory, SQLite, JSONL), hot-swapping of tool/extension code while an agent is running, and multiplayer state sync (multiple users or UIs can connect to and steer the same agent simultaneously).

**Why it matters:** Most people building agent workflows are either building on top of heavyweight frameworks (LangChain, CrewAI) or rolling their own loops from scratch. Pi is aimed at the gap in between: a stable, production-hardened harness that doesn't dictate your architecture. The crash survival alone changes what you can safely hand off to long-running agents — right now, a process restart means losing the entire run. Hot-swapping is the other underappreciated feature: you can iterate on an agent's tools while it's in the middle of a task. This is the infrastructure shift that makes agents feel less like "it ran once and I got an output" and more like a persistent system you can maintain.

**Format:** Explainer (what a "harness" is and why it matters), with a Tip angle (Pi as a concrete thing to try)

**Reel angle:** "Everyone talks about AI agents crashing — this is why, and the open-source framework that just fixed it"

### 3. Cursor shipped two bots for "the last mile" and improved token efficiency for long runs — in the same week

**What it is:** Two Cursor releases back-to-back. First: Rollouts (a bot that does staged deployment review and validation) and Security Review (a bot that proactively scans for vulnerabilities as you work — not after a PR is already open). Second: improved token efficiency for longer agent runs — fewer tokens consumed per step on extended multi-turn tasks, which directly affects both cost and context headroom for complex projects.

**Why it matters:** The token efficiency update is the less flashy but more immediately useful of the two. Long agent runs in Cursor have been hitting context limits and ballooning in cost — the people who use Cursor for full-feature implementation rather than single-file edits have been the most blocked by this. The Rollouts + Security bots are interesting as a signal: Cursor is moving from "AI writes code" toward "AI handles the full software lifecycle," including the operational parts (deploy safety, security review) that historically require senior judgment. These aren't experiments — they're shipping to users.
